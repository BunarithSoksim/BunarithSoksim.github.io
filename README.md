# Bunarith Soksim — Portfolio

Personal portfolio website. Plain HTML, CSS and JavaScript, no build step.

## Files
- `index.html` — page content
- `style.css` — all styles (light and dark mode)
- `script.js` — copy buttons for email and phone
- `images/` — profile photo (add project screenshots here)

## Run locally
Open `index.html` in a browser, or use the VS Code "Live Server" extension.

## Deploy to GitHub Pages
1. Create a new public repo named `BunarithSoksim.github.io`.
2. Upload all files in this folder (keep `index.html` at the root).
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After about a minute the site is live at `https://bunarithsoksim.github.io`.

## Certificates
PDFs and preview images live in `certificates/`. Clicking a certificate image opens the PDF.
